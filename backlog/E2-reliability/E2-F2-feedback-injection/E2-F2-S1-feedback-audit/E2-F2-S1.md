## Description

This story audits every retry branch in `src/devbench/execution/orchestrator.py` to confirm that `previous_feedback` is populated with the output from failed judges and passed to `claude_executor.execute()` on every retry call. Any branch found to omit the feedback is fixed. A regression test is added to `tests/test_execution/test_orchestrator.py` that mocks `execute()` and asserts the feedback from a prior failed judge is present in the subsequent call.

### Tier 2: Contextual Rules — Python

- Collect all feedback strings from failed judge results into a list; join with `\n\n---\n\n` separator
- Pass the joined string as `previous_feedback`; never `None` after retry 1
- Use `unittest.mock.patch` in the regression test to intercept `execute()` calls and capture `call_args`
- Assert on the specific feedback text, not just non-None

## Test Plan (Spec-Driven TDD)

### Contract Definition

The orchestrator's retry loop must track `previous_feedback: str = ""` and on each failed judge, append the judge's feedback to this accumulator. Every call to `execute()` after the first passes `previous_feedback=previous_feedback`. The regression test structure:

```python
def test_feedback_injected_on_retry():
    # Arrange: mock execute() to return a result that fails a judge on attempt 1
    # Act: run orchestrator retry loop
    # Assert: second call to execute() has previous_feedback containing judge feedback
```

### Acceptance Tests (BDD-style)

# AC-1: feedback populated on retry
Given a work unit whose first execution produces a failing SecurityReviewJudge verdict with feedback "Fix SQL injection"
When the orchestrator retries
Then `execute(previous_feedback=...)` is called with a string containing "Fix SQL injection"

# AC-2: feedback accumulates
Given two consecutive failed executions with judge feedback "Fix A" and "Fix B"
When the orchestrator attempts a third execution
Then `previous_feedback` contains both "Fix A" and "Fix B"

# AC-3: first call may be empty
Given a work unit being executed for the first time
When `execute()` is called
Then `previous_feedback` is `None` or `""`
