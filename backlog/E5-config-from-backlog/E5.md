## Description

This epic introduces a single YAML configuration source located under the backlog directory and applies a clear precedence model. The config file provides environment-style settings plus repository metadata, including optional per-repo `default_branch`. Runtime behavior must remain deterministic: path selection via existing top-level `--config`, values loaded from YAML, and environment overrides applied on top.
