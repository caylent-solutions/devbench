# E2-F2-S1: `kanon list` implementation across all flags

## Status: in-queue

## Description

Single-story decomposition of the `kanon list` implementation. Six tasks
in strict sequence (T1 -> T2 -> ... -> T6) so each flag lands as an
independent commit on top of the same command module
(`src/kanon_cli/commands/list.py`).

T1 introduces the command shell and the default output. Each subsequent
task extends the command with one flag (or flag-cluster). The story closes
when T6 lands and the full integration suite for `kanon list` is green.

Spec source: spec Section 4.1.
