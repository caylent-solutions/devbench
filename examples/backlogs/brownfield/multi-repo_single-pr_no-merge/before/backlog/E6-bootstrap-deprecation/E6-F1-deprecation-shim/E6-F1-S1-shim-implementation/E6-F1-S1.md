# E6-F1-S1: Shim implementation (core + flag translation + help text)

## Status: in-queue

## Description

Story scope: rewrite `src/kanon_cli/commands/bootstrap.py` to be the
deprecation shim per spec Section 4.9. The story is decomposed into
three tasks executed in dependency order:

1. **T1 -- Shim core**: replace today's `_run` with code that prints
   the WARN to stderr and raises `SystemExit(EXIT_CODE_DEPRECATED)`
   without importing `core/catalog.py` or `core/bootstrap.py`. Delete
   `src/kanon_cli/core/bootstrap.py` entirely (no consumers remain
   after this story). Add `EXIT_CODE_DEPRECATED = 3` to
   `src/kanon_cli/constants.py`.
2. **T2 -- Flag translation**: add a pure-function translator that
   maps today's bootstrap argv (`<package>`, `--catalog-source`,
   `--output-dir`) to the equivalent `kanon add` / `kanon list` argv
   string. Cover every flag case including the no-equivalent cases
   (`--output-dir` for `add`; any non-`--catalog-source` flag for
   `list`). Output is text only -- the shim does NOT execute the
   translated command.
3. **T3 -- `--help` text**: prepend the DEPRECATED notice and embed
   the verbatim flag translation table inside the argparse
   `description`. Help exits 0 (per spec Section 4.9 behaviour table,
   last row).

T1 must land before T2 because T2's translator imports the
EXIT_CODE_DEPRECATED constant and shares the WARN-text helper. T3
depends on T1 (description text format) and T2 (the table content
T3 prints inside `--help` is the same table T2's translator
references).

Spec source: `spec/kanon-list-add-lock-features-spec.md` Section 4.9
(`kanon bootstrap` deprecated -- behaviour table, flag translation
table, exit code 3, `--help` DEPRECATED prefix) and Section 14 help
snapshot rule.
