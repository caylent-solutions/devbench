# E7-F1-S1: shtab integration and PREAMBLE shell helpers

## Status: in-queue

## Description

Story scope: introduce the `kanon completion <shell>` subcommand and
the `PREAMBLE` dict that the subcommand passes to
`shtab.complete(parser, shell, preamble=PREAMBLE)`. The story ships
in two tasks that run in this order:

- **T1** registers the subcommand in `src/kanon_cli/commands/completion.py`
  + `src/kanon_cli/cli.py`, adds `shtab>=1.7.0` to `pyproject.toml`,
  and wires the call to `shtab.complete()` with an initially-empty
  `PREAMBLE` import target.
- **T2** authors the `PREAMBLE` dict's bash and zsh contents:
  the kanon-specific shell helper functions that shell out to
  `kanon __complete_*` hidden subcommands plus the mid-token splitter
  helper (Section 11.5).

T2 depends on T1 only because T2 needs the import target
(`src/kanon_cli/completions/preamble.py::PREAMBLE`) to exist before
T2 can populate it; T1 wires the import path and leaves the dict
ready for T2 to fill.

Spec source: spec Section 11.1 (subcommand contract) and Section 11.5
(mid-token splitter helper).
