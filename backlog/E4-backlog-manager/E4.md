## Description

This epic cleans up backlog state management naming and ownership. The current class name (`BacklogManagerJudge`) implies review behavior, but the class is used as a lifecycle/status manager. The epic renames the class to `BacklogManager`, removes `BaseJudge` coupling, and updates imports/usages so runtime behavior stays the same while responsibilities become explicit.
