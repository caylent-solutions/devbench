# E8-F1: New docs under `docs/` for the list / add / lock feature set

## Status: in-queue

## Description

Authors 16 NEW Markdown documents under `caylent-solutions/kanon/docs/`. Each
document is the operator-facing reference for one slice of the feature set;
together they form the doc surface the spec's Section 8 enumerates as "NEW".

Every new doc:

- Uses the canonical terminology from spec Section 1.1 verbatim (manifest repo,
  catalog source, catalog entry, entry name, source name, `.kanon` file,
  `.kanon.lock` file, install workspace).
- Cross-links to its siblings where the spec calls for it (e.g.,
  `docs/catalogs-explained.md` is linked from every missing-catalog-source error
  message snapshot; `docs/git-auth-setup.md` is linked from every git-auth error
  snapshot; `docs/migration-bootstrap-to-add.md` is linked from the bootstrap
  WARN line and from the CHANGELOG).
- Names its features against the spec verbatim; no paraphrasing of normative
  rules (soft-spots 1-5, error message shapes, exit-code table, env-var names).
- Is renderable as plain GitHub-flavored Markdown without a build step
  (renders cleanly under `mkdocs build --strict` if a mkdocs config is present;
  passes `markdownlint` with the repo's existing config).

Each task in this feature has its own Story sub-directory entry under
`E8-F1-S1-write-new-docs/` and is independently executable.

Spec source: `spec/kanon-list-add-lock-features-spec.md` Section 8 (the
sixteen NEW bullets) plus the per-doc cross-references noted in each task.
