# E10-F1-S1: README.md + docs/contributing.md (codify catalog-entry contract)

## Status: in-queue

## Description

Single story containing one Markdown-tier task that updates `README.md`
and creates-or-updates `docs/contributing.md` in `caylent-private-kanon`.
Both documents codify the same catalog-entry contract derived from spec
Section 3.5 (the five soft-spot rules) and Section 9a (PEP 440
tag-publishing convention).

The story is one task (not split per-file) because the two docs share a
single contract description that must stay consistent: splitting the
work would create drift risk between `README.md`'s contract summary and
`docs/contributing.md`'s authoring procedure.

Spec source: `spec/kanon-list-add-lock-features-spec.md` Section 9a
(Docs subsection); Section 3.5 (soft-spot rules 1-5).
