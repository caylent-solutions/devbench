# E11-F3: Migrate the `immutable-audit-trail` catalog entry

## Status: in-queue

## Description

Bring the `immutable-audit-trail` catalog entry into Section 3.5 soft-spot
compliance. The entry's manifest XML lives at
`repo-specs/common/sdlc/general/pr-ready/immutable-audit-trail/immutable-audit-trail-marketplace.xml`
and the legacy author-facing README lives at
`catalog/immutable-audit-trail/README.md`. The XML filename and the
catalog directory name agree, so no rename is required: the canonical
entry-name is `immutable-audit-trail`.

Today's `<catalog-metadata>` block carries `display-name="Immutable Audit
Trail"`, `type`, `description`, `owner-name`, `owner-email`, `keywords`,
and `version` as attributes but is MISSING the REQUIRED `<name>` element.
The single referenced `<project>` revision pins
`refs/tags/development/sdlc/general/pr-ready/immutable-audit-trail/>=0.3.0,<1.0.0`
against the inherited `caylent` remote (resolved via
`repo-specs/git-connection/remote.xml`); the PEP 440 last-path-component
of that constraint is `>=0.3.0,<1.0.0`, which IS PEP 440 compliant.

This feature decomposes into a single story (`E11-F3-S1`) with a single
task (`E11-F3-S1-T1`).

Spec source: spec Section 9b Phase 1; Section 3.5 soft-spot rules 1-5.
