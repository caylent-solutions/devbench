# E6-F1: Deprecation shim for `kanon bootstrap` and `kanon bootstrap list`

## Status: in-queue

## Description

Rewrite `src/kanon_cli/commands/bootstrap.py` so the command no
longer performs any work. Per spec Section 4.9:

- Any invocation OTHER THAN `--help` prints a WARN to stderr whose
  verbatim text comes from the Section 4.9 behaviour table (names the
  exact replacement command -- `kanon add <name>` or `kanon list` --
  and includes the per-flag translation notes from the flag
  translation table), then exits with status 3.
- `--help` (or no positional arg) prints argparse's normal `--help`
  output prepended with `DEPRECATED: 'kanon bootstrap' is replaced by
  'kanon add' and 'kanon list'. See docs/migration-bootstrap-to-add.md.`
  and includes the verbatim flag translation table inline; exit code
  is 0 (help is informational).
- The shim does NOT call into `core/catalog.py`, `core/bootstrap.py`,
  `<catalog-metadata>` parsing, or any filesystem mutator. The legacy
  module `src/kanon_cli/core/bootstrap.py` is deleted entirely.
- A new constant `EXIT_CODE_DEPRECATED = 3` is added to
  `src/kanon_cli/constants.py` (reserved across kanon for "deprecated
  invocation"; documented in `docs/exit-codes.md`).
- Argv translation is a static string transformation only (no
  semantic evaluation). The translation table:
  - `<package>` positional -> `<name>` positional (identical).
  - `--catalog-source <v>` -> `--catalog-source <v>` (identical).
  - `--output-dir <v>` -> no equivalent; WARN explains `"the install
    workspace is the current directory or KANON_WORKSPACE_DIR if
    set"`.
  - `bootstrap list` translates only `--catalog-source`; any other
    flag produces a generic `"--<flag> has no equivalent in 'kanon
    list'"` notice in the WARN.

This feature is split into three tasks (one story) so each PR is
reviewable in isolation:

- **T1**: shim core (WARN text + exit 3 + zero boundary calls + delete
  `core/bootstrap.py` + add `EXIT_CODE_DEPRECATED` to `constants.py`).
- **T2**: flag translation table (parametrised argv transformation
  function covering every today-flag and the no-equivalent cases).
- **T3**: `--help` DEPRECATED prefix and retained discoverability
  (argparse description / formatter_class adjustment, inline flag
  translation table in help text).

Each task lists its source `.py` file and its matching
`tests/unit/test_<basename>.py` (source/test atomicity per
`devbench/docs/source-test-atomicity.md`). Together they replace the
existing `commands/bootstrap.py` and the existing
`tests/unit/test_commands_bootstrap.py` / `tests/integration/test_*`
bootstrap tests.

Tab completion under `kanon bootstrap <TAB>` is preserved (spec
Section 4.9: completion runs in a separate process invoked by the
shell at tab-time and is permitted to read manifest-repo content via
the same `__complete_catalog_entries` helper used by `kanon add`); the
shim's no-boundary-call rule applies to the invocation path only.

Spec source: `spec/kanon-list-add-lock-features-spec.md` Section 4.9
plus Section 14 `kanon bootstrap --help` snapshot.
