## Description

Extend the not-found path of `kanon why` (introduced in E4-F2-S1-T1 and elaborated in T2) with a
Levenshtein-distance-bounded closest-match suggestion. Per spec Section 4.5 step 5:

- When the requested node is not in the tree across any of the three matching categories (URL,
  XML path, source name), the command emits a hard error to stderr that includes the top 3
  closest matches drawn from the union of source names + project URLs + XML paths in the resolved
  tree.
- Closest-match is computed via Levenshtein edit distance against the argument string. Only
  candidates with **edit distance <= 3** are eligible. The suggestion list is sorted ascending by
  distance and truncated to at most 3 entries.
- When zero candidates are within edit distance 3, the error message reports the not-found error
  with no suggestion list (the message states explicitly that no close matches were found,
  consistent with the standard `ERROR: <summary>` shape).

To keep the helper reusable and unit-testable in isolation, the Levenshtein implementation lands
in a dedicated module `src/kanon_cli/utils/levenshtein.py` with its matching
`tests/unit/test_levenshtein.py`. The helper exposes a single public function
`levenshtein_distance(a: str, b: str) -> int` returning the Damerau-free edit distance (insertion,
deletion, substitution; no transpositions, matching the spec's "Levenshtein" wording).

The closest-match suggester in `why.py` (call it `_suggest_closest_matches(argument, universe,
max_distance, top_n)`) accepts the universe of strings to compare against (the union of source
names, XML paths, and project URLs from the resolved tree), filters to `distance <= max_distance`,
sorts ascending by `(distance, value)` for deterministic output, and returns the top `top_n`.

The constants `KANON_WHY_SUGGEST_MAX_DISTANCE` (default 3) and `KANON_WHY_SUGGEST_TOP_N` (default
3) live in `src/kanon_cli/constants.py` so the thresholds are not hard-coded in source.

Spec source: `spec/kanon-list-add-lock-features-spec.md` Section 4.5 step 5.
