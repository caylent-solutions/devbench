## Description

This feature adds `JUDGE_PROMPTS_DIR` support to DevBench so that teams can provide custom judge prompts without modifying the source code. The change is minimal: `config.py` gains a `PROMPTS_DIR` constant (optional path), and `load_prompt()` is updated to check that directory first before falling back to the default `prompts/` directory. The variable is also added to `shell.env.example` so users know it is available. The feature requires E0 to be complete so `shell.env.example` already exists with the full env var set.

## Test Plan (Spec-Driven TDD)

### Contract Definition

```python
# config.py
PROMPTS_DIR: Optional[Path] = Path(os.environ["JUDGE_PROMPTS_DIR"]) if os.environ.get("JUDGE_PROMPTS_DIR") else None

# load_prompt()
def load_prompt(name: str) -> str:
    """Load a prompt file by name. Checks PROMPTS_DIR first, falls back to default."""
    if PROMPTS_DIR is not None:
        override = PROMPTS_DIR / name
        if override.exists():
            return override.read_text()
    default = Path(__file__).parent.parent.parent / "prompts" / name
    return default.read_text()
```
