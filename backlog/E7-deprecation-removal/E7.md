# E7: Deprecation Removal

## Status: in-queue

## Description

E5 introduced `JUDGE_ALLOWED_REPOS`, `JUDGE_BACKLOG_ROOT`, and `JUDGE_BACKLOG_INDEX` as deprecated
with warning-only backward compatibility. E7 completes the deprecation cycle: removes the compat
shims, strips the deprecated env vars from all docs, and eliminates the related tests that exercised
the old behavior.

After this epic, the three env vars are fully unsupported. Any operator still setting them will see
no effect and no warning — the vars are simply ignored (or absent from the config layer entirely).
