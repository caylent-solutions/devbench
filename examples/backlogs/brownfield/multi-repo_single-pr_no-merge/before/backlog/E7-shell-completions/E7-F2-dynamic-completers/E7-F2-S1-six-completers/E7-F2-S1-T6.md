## Description

Implement the `__complete_cached_catalogs` dynamic completer
(Section 11.3 row 6). New hidden subcommand
`kanon __complete_cached_catalogs <current-token>` that:

1. Enumerates entries under `${KANON_CACHE_DIR}/catalogs/*/`. Each
   subdirectory's name is `<sha256-of-catalog-url@ref>`; the
   sha256 is opaque, so the completer reads the SHA -> URL@ref
   mapping from a sidecar `catalogs/<sha>/origin.txt` written by
   the cache layer (E7-F3-S1-T1 owns the sidecar contract).
2. Emits one `<url>@<ref>` string per line, sorted, prefix-filtered
   by `<current-token>`.
3. Returns empty if `${KANON_CACHE_DIR}/catalogs/` does not exist
   (first-run / empty cache) -- this is NOT an error; no log entry.

Used by: the global `--catalog-source <url>@<ref>` flag (Section
11.2 row).

Failure handling: identical to T1-T5 for I/O errors, malformed
`origin.txt`, etc.

Spec source: spec Section 11.3 row 6, Section 11.2 (the
`--catalog-source <url>@<ref>` row), Section 11.4 cache layout (the
`catalogs/<sha>/origin.txt` sidecar is part of E7-F3-S1-T1's cache
layout deliverable).
