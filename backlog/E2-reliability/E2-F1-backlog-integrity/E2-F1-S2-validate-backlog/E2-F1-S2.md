## Description

This story adds the `devbench validate-backlog` subcommand to the CLI and wires it as a pre-flight check at the top of the orchestrator's main loop. The command checks four things: every BACKLOG.md row points to an existing file, every work unit file's status matches its BACKLOG.md row, no orphaned work unit files exist without an index row, and all dependency IDs in the index reference real work unit IDs. It exits non-zero with actionable error messages when any check fails.

def validate_backlog(backlog_root: Path) -> list[str]:
    """
    Validate the backlog directory for consistency.

    Checks:
    - Every BACKLOG.md row's File Path exists on disk

        List of error description strings. Empty list means valid.
