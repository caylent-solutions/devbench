## Description

This epic makes DevBench's judge prompts overridable by users without forking or modifying the installed package. Currently all prompts are loaded from a fixed `prompts/` directory relative to the package. After this epic, `load_prompt()` first checks `JUDGE_PROMPTS_DIR` (if set) and falls back to the default `prompts/` directory. This enables teams to customise judge behaviour for their specific standards without maintaining a fork. E3 depends on E0 so that `JUDGE_PROMPTS_DIR` can be documented in `shell.env.example` alongside the other environment variables.

### Tier 2: Contextual Rules — Python

- `PROMPTS_DIR` is `Optional[Path]` — `None` means use the default `prompts/` directory
- `load_prompt()` should try `PROMPTS_DIR / filename` first; if the file does not exist there, try the default path
- Log at DEBUG level which directory is being used for each prompt load
