## Description

Implement the `tag-format` check inside
`src/kanon_cli/commands/catalog.py` per spec Section 3.5 soft-spot rule 5
and spec Section 0.4.

The check (`_check_tag_format(target_path, ls_remote_callable)`) warns
about tags in the manifest repo whose last path component is not a valid
PEP 440 version. These tags are unaddressable by kanon's resolver
(`version.py::_resolve_constraint_from_tags`).

Behaviour:

- Read the manifest repo's tags via `git ls-remote --tags <target_path>`.
  When the audit target is a local directory, `<target_path>` is the
  directory; when the audit target was a cloned `<url>@<ref>` source,
  `<target_path>` is the cache clone path.
- For each tag, take the last `/`-delimited path component and attempt
  `packaging.version.Version(<component>)`.
- Tags whose last path component fails to parse => WARN finding (one
  per tag, capped at `KANON_CATALOG_AUDIT_TAG_REPORT_LIMIT`, default 50;
  beyond the cap, emit a single summary WARN noting the remaining count).
- Warning-only (not error) per spec Section 0.4. Manifest repos with
  legitimate non-version tags (ops markers, release-prep tags) still
  work; the warning surfaces unaddressability so authors decide whether
  to rename tags to PEP 440 form.

Monorepo-style tags (`subpackage/1.0.0`) parse cleanly because we look
at the LAST `/`-delimited path component only (`1.0.0` is PEP 440).
Mixed monorepo prefixes are supported.

The `ls_remote_callable` is injected as a parameter so unit tests do not
depend on network. The integration test runs against a real fixture git
server.

Register the check in the registry T1 created under name `tag-format`.

Source-test atomicity: this task modifies `catalog.py` (existing after
T1) and `constants.py` and adds new tests. Fixture: the existing fixture
git server is used; no XML fixtures needed.

Spec source: spec Section 3.5 soft-spot rule 5; Section 4.8 (`--check
tag-format`); Section 0.4 (loud-error and audit-warn semantics for
non-PEP-440 tags); Section 4.0 rule 1 (PEP 440 constraint resolution).
