## Description

This feature adds a structured YAML config under the backlog directory and integrates it into runtime configuration loading. The YAML includes repository definitions and optional default branches, plus environment-style keys used by existing config behavior. It enforces a single, visible precedence model and avoids expanding CLI surface area beyond the existing `--config` path option.
