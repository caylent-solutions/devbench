# E7-F4: bash + zsh coverage integration tests and snapshot tests

## Status: in-queue

## Description

100%-coverage acceptance for the completion feature (spec Section 11.9):

1. Every row of the Section 11.2 matrix has a passing integration test
   under bash and under zsh that sources the generated completion
   script and asserts the candidate list returned for the row's
   command/arg/flag combination matches the expected set.
2. `kanon completion bash` and `kanon completion zsh` produce shells
   that pass `shell -n` syntax check.
3. Snapshot tests on the generated scripts (`tests/fixtures/completion/expected-bash.sh`,
   `expected-zsh.sh`) fail CI on diff. Refresh workflow:
   `make update-completion-snapshots`.

Three tasks:

- **T1** -- bash integration tests under `tests/integration/test_completion_bash.py`.
  Sources the generated script in a test container that has bash >= 4.0
  installed (macOS stock bash 3.2 is documented as not supported).
  Exercises tab-completion via the `compgen -F` shell helper. Asserts
  the candidate list for every row of Section 11.2 matches the
  expected set.
- **T2** -- zsh integration tests under `tests/integration/test_completion_zsh.py`.
  Same shape but uses `_main_complete`.
- **T3** -- snapshot tests under `tests/functional/test_completion_snapshots.py`,
  comparing `kanon completion bash` / `zsh` output against golden
  files. Updates `Makefile` with a `update-completion-snapshots`
  target.

These tests transitively depend on every E7-F1/F2/F3 task because they
exercise the full surface end-to-end.

Spec source: spec Section 11.8 (testing requirement) and 11.9
(acceptance for 100% coverage).
