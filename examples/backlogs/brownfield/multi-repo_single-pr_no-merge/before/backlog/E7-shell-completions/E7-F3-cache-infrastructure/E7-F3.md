# E7-F3: Cache infrastructure for network-backed completions

## Status: in-queue

## Description

Every network-touching completer reads through a TTL cache so a warm
tab-press has no network round-trip. This feature ships the cache
plumbing that the six dynamic completers (E7-F2) consume.

Artefacts:

- **Cache layout** under `${KANON_CACHE_DIR}` (Section 11.4): two
  subdirectories `catalogs/<sha256-of-catalog-url@ref>/` and
  `projects/<sha256-of-project-repo-url>/`, each holding `index.txt`
  / `tags.txt` / `fetched_at.txt` / `accessed_at.txt`. Directories
  created mode `0700`; files created mode `0600`. A
  `completion-errors.log` lives at the root.
- **TTL math** with clock-skew handling: if `fetched_at` is within
  `KANON_COMPLETION_CACHE_TTL` of now, return contents immediately;
  if stale, return current contents AND fork a background refresh
  (gated by `KANON_COMPLETION_REFRESH_BG`). `fetched_at` in the future
  -> treat as fresh; negative or non-numeric -> treat as missing.
- **`accessed_at` coalescing** to avoid write amplification on rapid
  tab presses: only update `accessed_at.txt` when the current epoch
  is more than `KANON_ACCESSED_AT_COALESCE_SEC` past the prior value
  (default 60s).
- **Output sanitization**: every candidate written to a cache file
  passes through a sanitizer that rejects entries containing newlines,
  NULs, or shell metacharacters. Rejected entries are dropped from
  the cache file AND logged to `completion-errors.log`.
- **Background refresh on stale**: when a cache file is stale but
  present, return the current contents synchronously AND fork a
  detached process to refresh in the background (`os.fork()` +
  detached child running `_refresh()`).

Constants added to `src/kanon_cli/constants.py`:
`KANON_CACHE_DIR`, `KANON_COMPLETION_CACHE_TTL=300`,
`KANON_COMPLETION_TIMEOUT=2`, `KANON_COMPLETION_REFRESH_BG=1`,
`KANON_COMPLETION_ENABLED=1`, `KANON_ACCESSED_AT_COALESCE_SEC=60`,
`KANON_COMPLETION_LOG`.

Spec source: spec Section 11.4 (caching) and Section 3.6 trust model
("Cache files are user-private", "Completion candidates are
shell-escaped").
