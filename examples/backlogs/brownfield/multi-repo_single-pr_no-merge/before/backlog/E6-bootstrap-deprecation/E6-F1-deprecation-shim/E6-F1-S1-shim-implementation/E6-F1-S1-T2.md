## Description

Add a pure-function flag translator inside
`src/kanon_cli/commands/bootstrap.py` that maps today's `kanon
bootstrap` argv into the equivalent `kanon add <name>` or `kanon
list` argv string. The translation is a static string transformation
ONLY -- the shim does NOT execute the translated command, does NOT
parse semantically, does NOT validate flag values; it simply prints
the translation inside the WARN body so the operator can copy-paste
the replacement command.

T1 supplied the WARN-text helper `_format_deprecated_warn(invocation,
replacement_argv_tail)` with `replacement_argv_tail` defaulted to the
empty string. T2 wires in the real translator: a new
`_translate_bootstrap_argv_tail(args: argparse.Namespace) -> str`
function whose output becomes the `[...translated flags]` portion of
the WARN body.

The flag translation table per spec Section 4.9 (verbatim):

| Bootstrap flag (today) | Replacement (`kanon add`) | Replacement (`kanon list`) | Notes |
|---|---|---|---|
| `<package>` positional | `<name>` positional | (n/a -- `bootstrap list` triggers `kanon list`) | identical semantics |
| `--catalog-source <v>` | `--catalog-source <v>` | `--catalog-source <v>` | identical |
| `--output-dir <v>` | (no equivalent) | (no equivalent) | WARN includes: `"--output-dir has no direct equivalent in 'kanon add'; the install workspace is the current directory or KANON_WORKSPACE_DIR if set."` |

`kanon bootstrap list` flag set: only `--catalog-source` is
meaningful. Any other flag (today, only `--output-dir` exists)
triggers a generic `"--<flag> has no equivalent in 'kanon list'"`
notice appended to the WARN body.

Worked translation examples (verbatim output of
`_translate_bootstrap_argv_tail`):

- `kanon bootstrap kanon` -> tail `""` (no flags to translate). WARN
  body shows `    kanon add kanon`.
- `kanon bootstrap kanon --catalog-source https://example.com/x.git@main` ->
  tail `"--catalog-source https://example.com/x.git@main"`. WARN body
  shows `    kanon add kanon --catalog-source
  https://example.com/x.git@main`.
- `kanon bootstrap kanon --output-dir ./scratch` -> tail `""` plus an
  appended notice line:
  `Note: --output-dir has no direct equivalent in 'kanon add'; the
  install workspace is the current directory or KANON_WORKSPACE_DIR
  if set.`
- `kanon bootstrap list --catalog-source https://example.com/x.git@main` ->
  tail `"--catalog-source https://example.com/x.git@main"`. WARN
  body shows `    kanon list --catalog-source
  https://example.com/x.git@main`.
- `kanon bootstrap list --output-dir ./scratch` -> tail `""` plus an
  appended notice line:
  `Note: --output-dir has no equivalent in 'kanon list'.`

The translator is a pure function (no side effects, deterministic for
identical input) so it is exhaustively covered by parametrised unit
tests. Each table row above is one or more parametrised cases.

Spec source: `spec/kanon-list-add-lock-features-spec.md` Section 4.9
flag translation table + `kanon bootstrap list` flag set paragraph.

2. **NO SILENT FAILURES** -- Every error must produce a clear, actionable error message sent to stderr. Every error must result in a non-zero exit code. Never swallow exceptions. Never log-and-continue when the operation was required to succeed.
