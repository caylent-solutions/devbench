# E13-F1: Audit kanon-claude-marketplaces and produce a follow-up-issue report

## Status: in-queue

## Description

Run the four kanon audit / validate commands shipped by E5 against the
`caylent/kanon-claude-marketplaces` working tree, capture every finding,
classify each finding by severity, and author a comprehensive Markdown
audit report committed to the target repo at
`audit-reports/2026-05-kanon-deps-spec-audit.md`. The report's body
includes:

1. Every audit / validate finding listed under its corresponding
   soft-spot rule (spec Section 3.5 rules 1-5) or trust-model section
   (spec Section 3.6).
2. Severity classification (ERROR / WARN / INFO) for each finding.
3. A ready-to-paste GitHub-issue body for each ERROR and WARN finding,
   so the operator can file them manually against the
   kanon-claude-marketplaces issue tracker via the GitHub UI.
4. Operator instructions for filing the recommended issues.
5. Provenance: the kanon-claude-marketplaces commit SHA the audit ran
   against AND a back-link to spec Section 9c.

The feature is intentionally read-only against the target repo's source
tree. The only file authored is the audit report itself.

Decomposition is one Story (E13-F1-S1) with one Task
(E13-F1-S1-T1) that does the audit and writes the report. Spec
Section 9c explicitly scopes this as a single backlog task; no further
decomposition is warranted.
