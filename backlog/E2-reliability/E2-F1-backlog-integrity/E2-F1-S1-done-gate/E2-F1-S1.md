## Description

This story adds two foundational reliability improvements to `src/devbench/backlog/manager.py`. The first is `require_judge_approval()`, a guard that raises `RuntimeError` if called with any non-PASS judge verdict, ensuring it is impossible to mark a work unit done without clean verdicts. The second is `set_status()`, a single write path that updates both the work unit file and BACKLOG.md in one function call, eliminating the file-divergence window that occurs when the two writes are separated.
