## Status: in-queue

## Description

Document the catalog-entry contract in the `caylent-private-kanon` repo so
catalog authors understand exactly what every `*-marketplace.xml` must
contain. Specifically:

- Update `README.md` to document the contract every catalog entry must
  satisfy: the soft-spot 1-5 rules from spec Section 3.5 (REQUIRED
  `<catalog-metadata>` fields, source-name derivation, entry-name
  uniqueness, `<remote>` resolvability, PEP 440 tag-name compliance).
- Create or update `docs/contributing.md` describing how to add a new
  catalog entry: a new `*-marketplace.xml` with a complete
  `<catalog-metadata>` block; NO per-entry directory. PEP 440
  tag-publishing convention documented.
- Remove every doc passage describing `catalog/<name>/` as the
  entry-author surface (replaced by `*-marketplace.xml` -- the only
  author-facing surface after E12 Phase 2 lands).

Spec source: `spec/kanon-list-add-lock-features-spec.md` Section 9a (Docs
subsection).
